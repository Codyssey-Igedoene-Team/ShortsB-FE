shortB 한국어 전문 15권 — 화면 파일 없이 본문만 전달하는 자료

1. 읽어서 확인: TXT 폴더의 책별 .txt 파일을 메모장, 텍스트 편집기, VS Code 등으로 열어주세요. UTF-8입니다.
2. 개발/DB 등록: books.json의 books 배열을 사용해주세요.
   - text: 해당 책의 한국어 전문 문자열 (요약 아님)
   - pages: 앱에서 사용하는 페이지 순서 배열 (0부터 시작)
   - pageJoiner: pages를 전문으로 재결합할 때 사용할 문자열
   - chapters: pages 기준 0부터 시작하는 [start, end) 범위
   - id, title, author, category, workType: 도서 식별/분류
   - sourceURL, licenseURL, credits, translationNote: 판본 및 출처 안내
   - textSHA256: text의 UTF-8 바이트 SHA-256
3. 한국어 원문 6권 + 공개 원문에서 새로 작성한 AI 한국어 전문 번역 9권입니다.
   AI 번역은 전문 번역가 교열 전입니다. 기존 출판사의 한국어 번역본이 아닙니다.
   영문판을 거친 중역 등 개별 판본 설명은 translationNote에 있습니다.
4. TXT는 제목·안내문을 앞뒤에 추가하지 않은 본문입니다. 도서명은 파일명과 JSON에서 확인하세요.
   전자 원자료의 순서와 표기를 유지했으며, 출판사의 실제 종이책 쪽수와 앱 쪽수는 다릅니다.
5. HTML 공유본은 본문 데이터가 assets/app.js에 묶여 있고,
   React 소스 공유본에는 src/data/catalog.json의 books[].parts에 들어 있습니다.
   이 자료는 동일한 본문을 사람이 읽기 쉬운 TXT와 개발용 JSON으로 추출한 것입니다.
6. 공개 원문·전자 텍스트 출처와 이용 안내는 JSON에 포함되어 있습니다. 원문 6권에는 위키문헌 출처를 표시해주세요.
