# shortB | 자투리 시간을 독서로

**shortB는 평소 독서에 시간을 투자하지 않는 사람과 자투리 시간을 독서에 활용하고 싶은 사람을 위한 독서 서비스입니다.**

책 한 권을 읽기 위해 긴 시간을 따로 마련하기보다, 출퇴근길이나 잠깐의 휴식 시간에 한두 페이지부터 읽을 수 있도록 돕습니다. 작은 분량의 독서가 이어 읽기와 기록으로 쌓이고, 자연스럽게 다음 이야기로 연결되는 경험을 목표로 합니다.

이 저장소는 shortB의 **React + TypeScript 기반 프론트엔드**입니다. 실제 앱 소스와 실행 환경은 [`front/`](./front)에 있습니다.

## 서비스 목표

- **시작의 부담 줄이기**: 로그인 전 두 페이지 체험으로 바로 책을 읽어볼 수 있습니다.
- **하루에 맞는 분량 정하기**: 하루 1·3·5·10페이지 중 목표를 선택해 짧은 시간에도 독서를 시작할 수 있습니다.
- **독서 흐름 이어가기**: 읽던 페이지와 스크롤 위치를 저장해 다음 자투리 시간에 이어 읽습니다.
- **작은 성취 남기기**: 읽은 페이지, 독서 달력, 표시한 문장을 통해 쌓이는 독서 경험을 확인합니다.
- **다음 독서로 연결하기**: 취향에 맞는 책과 읽은 작품의 다른 관점을 담은 대목을 추천합니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 첫 독서 체험 | 비로그인 상태에서 첫 두 페이지를 읽고, 체험 후에도 계속 읽기 선택 가능 |
| 추천 설정 | 생활 패턴, 하루 목표, 읽고 싶은 분위기와 관심 내용을 입력 |
| 오늘 읽기 | 읽던 책 또는 추천 도서와 오늘 읽을 범위, 목표 진행 상황 표시 |
| 독서 뷰어 | 페이지 이동, 글자 크기 변경, 진행 위치 확인, 읽던 위치 저장 |
| 문장 저장 | 본문에서 선택한 문장을 형광펜으로 표시하고 다시 확인 |
| 책 찾기 | 제목·작가·분위기 검색과 분위기·작품 길이 필터 |
| 나의 책장 | 읽던 책, 담은 책, 읽은 기록 관리 |
| 독서 달력 | 날짜별 독서 기록 확인 |
| 다른 관점 추천 | 독서 완료 후 작품 간 관점 비교와 연관 대목 읽기 |
| 로그인 | Google OAuth 및 서버 세션 확인, 개발 환경 전용 테스트 로그인 |

하루 목표는 **페이지 수**로 계산합니다. 같은 날 같은 판본의 같은 페이지는 중복 집계하지 않으며, 목표를 채운 뒤에도 계속 읽을 수 있습니다. 페이지는 앱에서 구성한 본문 단위입니다.

## 사용자 흐름

```text
첫 방문 → 두 페이지 체험 → 로그인 또는 게스트로 계속 읽기

로그인 → 최초 추천 설정 → 오늘 읽기 → 독서 → 완료
                                  ↑                ↓
                                  └── 다음 책 / 다른 관점 추천

재방문 → 필요 시 오늘 목표 설정 → 읽던 책 이어 읽기
```

책장과 달력에서 독서 기록을 확인하고, 취향과 하루 목표는 이후에도 변경할 수 있습니다. 첫 설정 이후에는 한국 시간 기준 새로운 날의 첫 접속에 오늘 목표를 선택합니다.

## 로컬 실행

**Node.js 22.12.0 이상과 npm**이 필요합니다. 아래 명령은 저장소 루트인 `ShortsB-FE`에서 시작합니다.

```sh
cd front
npm ci
npm run dev
```

기본 접속 주소는 `http://localhost:5173/`입니다. 포트가 사용 중이면 터미널에 표시되는 주소를 확인하세요.

백엔드 없이도 체험 독서가 가능합니다. 회원 화면은 개발 서버의 로그인 화면에 표시되는 **테스트 로그인**으로 확인할 수 있습니다. 테스트 로그인은 운영 빌드에서 제공하지 않습니다.

### 백엔드 연결 설정

`front/.env.example`을 같은 폴더의 `.env.local`로 복사합니다. PowerShell에서는 `front` 폴더에서 아래 명령을 실행합니다.

```powershell
Copy-Item .env.example .env.local
```

```dotenv
VITE_API_BASE_URL=http://localhost:8080
```

- Google 로그인은 백엔드의 `/oauth2/authorization/google`로 이동합니다.
- 사용자가 시작한 OAuth 흐름에서 돌아오면 `GET /api/me`로 세션을 확인합니다.
- 서버 로그아웃은 `GET /api/csrf`에서 받은 토큰을 사용해 `POST /api/logout`으로 요청합니다.
- 로컬 백엔드의 CORS 허용 출처와 로그인 성공·실패 이동 주소를 프론트엔드 주소에 맞춰야 합니다. 기본 개발 주소 기준 성공 경로는 `http://localhost:5173/`, 실패 경로는 `http://localhost:5173/login?error=google`입니다.
- 프론트엔드와 백엔드에서 `localhost`와 `127.0.0.1`을 혼용하지 않습니다.

`VITE_` 환경 변수는 브라우저에 공개되므로 비밀 키를 넣지 않습니다. API 주소를 변경한 배포에는 다시 빌드해야 합니다.

| `npm run format` | 코드 포맷 적용 |

## 주요 화면 경로

| 구분 | 경로 |
| --- | --- |
| 시작·체험 | `/`, `/trial`, `/trial-done` |
| 오늘 읽기·본문 | `/home`, `/book?book=waiting`, `/reader?book=waiting` |
| 완료·연관 추천 | `/complete`, `/discover` |
| 설정·탐색 | `/setup`, `/preferences`, `/goals`, `/search` |
| 책장·기록 | `/library`, `/calendar`, `/highlights` |
| 계정·안내 | `/login`, `/signup`, `/settings`, `/source`, `/about` |

로그인 상태와 체험 진행 상황에 따라 접근 가능한 화면이 달라집니다. 빌드 후 `/pages.html`에서 전체 화면 링크를 확인할 수 있습니다.

배포 시에는 `/reader`처럼 확장자가 없는 주소에 직접 접속하거나 새로고침할 수 있도록 **SPA fallback**을 설정해 `index.html`을 반환해야 합니다. 빌드 결과는 `front/dist/`에 생성됩니다.

## 현재 구현 범위

- **독서 기능**: 책 데이터, 추천, 하루 목표, 독서 기록, 책장, 문장 표시는 로컬 데이터와 브라우저 저장소로 동작합니다. 추천은 취향과 독서 이력을 활용하는 로컬 규칙 기반입니다.
- **인증**: Google OAuth와 서버 세션 확인·로그아웃 코드가 연결되어 있습니다. 카카오·Apple 로그인은 준비 중입니다. 일반 실행이나 새로고침만으로 인증 서버를 자동 호출하지 않습니다.
- **계정별 기록**: 회원 기록은 사용자 ID별로 해당 브라우저에 보관합니다. 기기 간 서버 동기화는 구현되어 있지 않으며, 브라우저나 접속 출처가 달라지면 같은 기록을 공유하지 않습니다.
- **콘텐츠 API**: 도서 수신 인터페이스, 조회 훅, OpenAPI R4 기반 요청·응답 타입과 클라이언트가 준비되어 있습니다. 현재 독서 화면은 서버 콘텐츠 API로 전환되어 있지 않습니다.
- **본문**: 한국어 원문 2편과 AI 한국어 전문 번역 5편을 제공하며, 번역 준비 중인 4편은 본문을 열 수 없습니다. AI 번역은 전문 번역가 교열 전이라는 안내를 출처 화면에 표시합니다.
